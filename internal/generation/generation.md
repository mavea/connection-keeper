# Пакет `internal/generation`

`generation` хранит одно поколение соединения и его счётчик удержаний.

## Основная семантика

- `retainCount` — это не только пользовательские ссылки из `Conn()`.
- В `retainCount` входит базовое удержание самого поколения, которое выставляется при создании.
- При выводе поколения из активной эксплуатации базовое удержание снимается.
- После этого поколение всё ещё может использоваться остаточными процессами, пока они не освободят свои удержания.
- Канал `WaitForClose()` закрывается только после снятия последнего удержания.

## Почему generation может жить после вывода из активной эксплуатации

Это ожидаемое поведение.

Вывод поколения из активной эксплуатации означает только то, что библиотека больше не считает его текущим рабочим поколением для новых операций lifecycle. Но уже начатые процессы могут ещё завершать работу с этим поколением. Поэтому закрытие поколения определяется не фактом handover/shutdown, а моментом, когда `retainCount` становится равен нулю.

## Input и Output поколения

- `NewInputGeneration` создаёт input-поколение и возвращает его с `HandoverGenerationFunc`.
- `HandoverGenerationFunc` вызывается один раз: он снимает базовое удержание поколения (отметка вывода из активной эксплуатации) и, если передан `handoverFunc`, запускает передачу ресурсов следующему поколению.
- `NewOutputGeneration` создаёт output-поколение и возвращает его с `ShutdownGenerationFunc`.
- `ShutdownGenerationFunc` вызывается один раз: он снимает базовое удержание поколения (отметка вывода из активной эксплуатации) и, если передан `shutdownFunc`, запускает остановку ресурсов.
- Эти функции не являются механизмом ретраев и описывают одноразовый шаг lifecycle.
- Контекст, переданный в `NewInputGeneration`/`NewOutputGeneration`, трактуется как контекст работы всей библиотеки и сознательно используется в `handover/shutdown` callback.

## `nil` callback

- `handoverFunc == nil` допустим для input-поколения.
- `shutdownFunc == nil` допустим для output-поколения.
- В этом случае поколение просто ждёт, пока завершатся остаточные удержания, без дополнительного callback дренажа.
