# Менеджер `kind`

`internal/kind/manager.go` содержит быстрый внутренний менеджер типов коннекторов.

## Назначение

`kindManager` хранит два связанных набора данных:

- `names` — канонические отображаемые имена, привязанные к нормализованному ключу;
- `kinds` — уже созданные `kind`, которые используются дальше как быстрые индексы.

Менеджер рассчитан на внутреннее использование библиотекой. Его цель — быстро выдавать стабильные положительные ID без явных `mutex` на основном пути работы.

## Особенности реализации

- Для конкурентного доступа используются `sync.Map` и `atomic.Uint32`.
- Создание `kind` допускает гонку между несколькими конкурентными вызовами `LoadOrStore`.
- Из-за этого в последовательности ID могут появляться дырки.
- Дырки в ID допустимы: для библиотеки важно только то, что каждый реально сохранённый `kind` получает свой положительный ID.
- Дополнительной проверки знака ID нет, потому что контракт `kind.ID()` уже гарантирует только положительные значения для созданных `kind`.

## Методы

### `RegisterName(s string)`

Регистрирует отображаемое имя заранее, но не создаёт `kind`.

- Параметры:
  - `s` — имя типа коннектора.
- Возвращаемое значение:
  - `error` — `ErrInvalidKind` для пустого имени или `ErrKindAlreadyRegistered` при повторной регистрации.

Пример: если сначала зарегистрировать `HTTP Client`, то последующий `GetOrCreate("http client")` создаст `kind` со строковым именем `HTTP Client`.

### `GetOrCreate(s string)`

Нормализует входное имя, ищет существующий `kind` и при необходимости создаёт новый.

- Параметры:
  - `s` — имя типа коннектора.
- Возвращаемые значения:
  - `domain.Kind` — найденный или созданный `kind`;
  - `bool` — признак, был ли `kind` создан в этом вызове;
  - `error` — ошибка нормализации имени.

Особенности:

- сравнение выполняется без учёта регистра;
- пробелы по краям отбрасываются;
- созданный `kind` получает положительный ID.

### `UnsaveGetOrCreate(sk, sv string)`

Быстрый внутренний путь без повторной валидации и нормализации.

- Параметры:
  - `sk` — уже нормализованный ключ;
  - `sv` — отображаемое имя.
- Возвращаемые значения:
  - `domain.Kind` — найденный или созданный `kind`;
  - `bool` — признак, был ли `kind` создан в этом вызове.

Важно: метод доверяет вызывающему коду. Если передать разные ключи, например `HTTP` и `http`, будут созданы разные `kind`.

### `GetList()`

Возвращает все уже созданные `kind`.

- Возвращаемое значение:
  - `[]domain.Kind` — снимок списка созданных `kind` на момент обхода `sync.Map`.

Особенности:

- порядок элементов не гарантируется;
- зарегистрированные через `RegisterName`, но ещё не созданные `kind`, в список не попадают.
