# Внутренний тип `kind`

`internal/kind/kind.go` содержит внутреннее представление типа коннектора.

## Назначение

Структура `kind` хранит две части идентификатора:

- `id int` — числовой индекс для быстрых обращений во внутренних менеджерах;
- `s string` — нормализованное текстовое имя.

## Методы

### `ID()`

Возвращает числовой идентификатор коннектора.

- Возвращаемое значение: положительный `int`, который используется как индекс в `registry` и `connector`.

### `String()`

Возвращает нормализованное строковое имя коннектора.

- Возвращаемое значение: строка.

## Договорённости

- `kind` — внутренняя структура пакета `internal/kind`.
- Внешний код работает с интерфейсом `domain.Kind`.
- `ID()` используется как быстрый индекс, поэтому его значение рассматривается как стабильное и положительное.
